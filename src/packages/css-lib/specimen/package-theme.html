Packaged CSS follows system preference

This page imports the freshly generated dist/barbajoe.css, the same CSS file included in the npm package. Change your system or browser color preference to compare the palette. It does not force a page theme.

The source catalog can force light and dark panels side by side. In this compiled build, color-scheme alone can change native controls but does not switch the library's semantic palette. Applications forcing a theme need matching semantic color-token overrides and a review of primary-button hover. Compiler-generated variables are not a public API.

Informational chip

Enabled appearance sample: inspect the resting face, hover with a pointer, and use Tab to see keyboard focus. Activation intentionally does not change data.
