Semantic color contract

Source catalog themes differ from the installed package. These side-by-side examples force light and dark themes using source CSS. The compiled package selects its palette from the system preference; setting only color-scheme on a panel does not switch that palette. Inspect the packaged-CSS example.

Applications forcing a theme must override semantic --barba-color-* tokens and review primary-button hover, as well as setting matching color-scheme. Do not copy compiler-private variables. Test contrast and native controls in the actual application build.

Every named text role below is guaranteed against both the page and surface backgrounds. Borders and focus rings have a separate non-text contrast guarantee.
